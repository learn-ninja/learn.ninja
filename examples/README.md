# Example lessons

The seven test lessons, as JSON files that follow spec v0.8: button hierarchy, writing a PRD, compound interest, Spanish greetings, and map vs forEach (all beginner), plus correlation vs causation (intermediate) and the Bronze Age collapse (advanced). Used as test fixtures, in Storybook, at `/lessons/{slug}` in the web app, and copied into `skills/learn/examples` as references for the skill (`npm run skill:build -w @workspace/cli`).
